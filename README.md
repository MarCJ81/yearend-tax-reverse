# 연말정산 13월의 월급 역산기

2026년 귀속 연말정산에서 **12월 31일 전에 무엇을 얼마나 해야 세금이 얼마 줄어드는지** 역산하는 정적 웹앱입니다.
`apps/yearend-tax-reverse/` — 서버·로그인·외부 요청 0건, 로컬 폰트, GitHub Pages 배포 전제.

## 왜 만들었나

- 홈택스 연말정산 미리보기는 **2026-10-28 ~ 12-18**만 열리고, 로그인·본인인증과 전년도 자료가 필요합니다.
- 카드 사용·연금계좌 납입·월세 지급은 **12-31**이 2026년 몫의 물리적 마감입니다.
- 기존 계산기는 “예상 환급액”을 정방향으로 보여주는 데서 끝납니다. 필요한 건 **“남은 기간에 뭘 해야 하나”**입니다.

## 핵심 기능

1. **30초 입력** — 총급여, 자녀 수, 신용카드, 체크·현금영수증, 대중교통, 전통시장, 연금저축, IRP, 월세. 고급 설정에 추가 부양가족 수.
2. **D-day 원장** — 홈택스 미리보기(12.18)와 결제·납입(12.31)까지 남은 일수를 KST 기준으로 계산.
3. **카드 25% 문턱 판정** — 문턱까지 남은 금액 또는 초과분, 기본한도·추가한도 게이지, **“지금 100만원 더 쓸 때 신용카드 vs 체크카드 실제 세금 차이”**.
4. **연금저축·IRP 역산** — 900만원(연금저축 600 + IRP 300) 한도까지 남은 금액과, 채웠을 때 늘어나는 세액공제(16.5% / 13.2%, 지방세 포함).
5. **월세 세액공제** — 17% / 15%, 연 1,000만원 한도, 요건 체크.
6. **12/31 전 액션 Top 3** — `안 써도 되는 돈(연금) → 이미 쓴 돈(월세) → 더 써야 하는 돈(카드)` 순서.
7. **결과 카드 PNG** — 1080×1350 Canvas. 총급여는 구간으로만 표시(개인정보 0건).
8. **iframe 퍼가기** — `?embed=1`로 머리말·꼬리말을 뺀 임베드 뷰, 하단에 “Powered by 원탭 도구 허브”.

## 가정 (결과 화면에도 그대로 노출)

- 인적공제 1인 150만원, 경로·장애인 추가공제 없음
- 국민연금 총급여 × 4.75%, 건강·고용보험 총급여 × 4.9673% (2026년 요율)
- 의료비·교육비·기부금·보장성보험료 세액공제 0원, 표준세액공제 13만원과 건강보험 소득공제 중 유리한 쪽 자동 선택
- 자녀는 9세 이상 기본공제 대상으로 가정
- 기납부세액 미입력 → **환급액이 아니라 ‘줄어드는 세금’**만 계산
- ISA 전환 추가한도 300만원, 도서·공연·체육 30% 별도 입력은 제외

## 디자인

A안 **Crisp Bento SaaS**(2026 Pinterest UI 리서치) 적용. 순백 타일 + 1px 보더 + 16px 라운드,
숫자는 산세리프 800 tabular, 액센트는 코발트 `#2F5BFF` 한 색만. 요약은 벤토 타일(큰 금액 타일 → 잉크 타일 → 지표 2타일 → D-day 띠).
본문 텍스트 대비는 모두 WCAG AA(4.5:1) 이상입니다(sub `#5B6067` 6.34:1, muted `#6B7076` 4.99:1, accent `#2F5BFF` 5.17:1).

## 계산 엔진 — decimal.js (MIT)

- 세율·한도·공제 계산을 전부 `decimal.js`(MIT, v10.6.0) 고정밀 연산으로 처리합니다. `assets/vendor/decimal.js`에 저장소 안 파일로 들어 있어 실행 중 외부 요청은 0건입니다.
- 반올림 정책: 금액 표시·세액공제는 원 단위 사사오입(`ROUND_HALF_UP`), 산출세액처럼 절사가 관행인 항목은 원 단위 절사(`ROUND_FLOOR`), 보험료율 곱셈은 40자리 정밀도로 계산합니다.
- `0.1 + 0.2`가 `0.30000000000000004`가 되는 부동소수 오차, `55,000,000 × 0.049673` 같은 세율 곱셈의 미세 오차가 결과에서 사라집니다.
- 검증: `node test.js` 209개 단언 (엔진 왕복·원단위 경계·기존 계산 회귀 포함), `python3 uitest.py` 실제 Chrome 83개 검사.
