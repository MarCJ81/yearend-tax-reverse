개인정보 처리방침

이 페이지는 무료 웹 계산기 연말정산 13월의 월급 역산기가 어떤 정보를 다루는지 설명합니다.

요약: 수집하는 개인정보가 없습니다. 총급여·카드 사용액·연금 납입액·월세는 서버로 전송되지 않고, 브라우저 저장소(쿠키·localStorage·sessionStorage)에도 남지 않습니다. 새로고침하면 입력값은 사라집니다.

1. 처리하는 정보

이용자가 화면에 입력하는 총급여, 카드 사용액, 연금계좌 납입액, 월세, 자녀·부양가족 수는 이용자 기기의 브라우저 메모리에서만 계산에 사용됩니다. 서버 전송, 회원가입, 로그인, 본인인증이 없습니다.

2. 수집하지 않는 정보

  • 이름, 주민등록번호, 주소, 전화번호, 이메일
  • 계좌번호, 카드번호, 비밀번호
  • 접속 기록, IP 주소, 기기 식별자
  • 위치 정보

3. 쿠키·분석 도구

쿠키를 쓰지 않고, Google Analytics 같은 외부 분석 도구나 광고 스크립트를 넣지 않습니다. 모든 파일은 이 사이트에서 직접 내려받아 쓰는 정적 파일이며, 외부 도메인으로 요청을 보내지 않습니다.

4. 결과 카드 이미지

공유 카드 PNG는 이용자 기기 안에서 Canvas로 그려져 다운로드됩니다. 카드에는 총급여 구간만 표시되고 정확한 총급여·월세·계좌 정보는 담기지 않습니다. 생성된 이미지는 어디에도 업로드되지 않습니다.

5. 외부 링크

결과 화면의 ‘원탭 도구 허브’, ‘부가세·종소세 계산기’, 출처 링크를 누르면 다른 페이지로 이동합니다. 이동한 페이지의 개인정보 처리 방식은 해당 사이트의 방침을 따릅니다.

6. 아동의 개인정보

만 14세 미만 아동의 개인정보를 수집하지 않습니다. 자녀 수를 입력하더라도 자녀의 이름·생년월일 등 식별 정보는 받지 않습니다.

7. 문의

이 계산기는 개인이 만든 무료 도구입니다. 계산 결과에 대한 이의나 정정 요청은 결과 화면의 출처 링크(국세청·국가법령정보센터)를 통해 공식 기준을 확인해 주세요.

8. 고지

이 도구의 결과는 모의 역산입니다. 실제 환급·추납액은 최종 총급여, 기납부세액, 의료비·교육비·기부금, 부양가족 요건에 따라 달라집니다. 확정 금액은 홈택스 연말정산 미리보기와 회사 정산 결과로 확인해야 합니다.
